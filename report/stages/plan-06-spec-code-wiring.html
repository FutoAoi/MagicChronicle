コード所有の再配置案

現在問題移動先
UIManager_Battle/Boss内のdraw/reset/hand操作表示クラスがカード保存則を所有し、二重実装Unity非依存RunDeckState + 共通HandController
CardMovement内の配置・支払い判断入力イベントがドメイン取引を所有PlaceMagicCircleCommandHandler
AttackMagicとTileSlotの直接相互呼出し順序がコールスタック依存ProjectileResolver + ResolutionQueue
GameManager.Updateのrun/phase遷移フレームループと状態機械が結合RunStateMachine、EncounterStateMachine
Effect*.OnExcuteから各Managerを直接操作効果の合成・テスト・previewが困難EffectResolutionがドメインイベントを返す
ScriptableObject assetのruntime mutation次ランへの漏れ、Editor asset汚染リスクimmutable definition + runtime instance
