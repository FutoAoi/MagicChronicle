UXの結論

MagicChronicleのUX目標は、情報を減らすことではなく、プレイヤーが「自分の一手で連鎖を作った」と因果を所有できることである。最大の阻害要因は、弾道、発火順、耐久消滅、敵弾が一度に動き、結果だけが派手に見えることである。

最優先の改善は、配置前の時系列preview、盤面上の残耐久、敵意図、解決後の短い因果ログである。これらは初心者支援であると同時に、上級者が深い最適化を行うための道具になる。

情報優先順位

  1. 現フェーズと確定可能性。
  2. 自弾・敵弾の起点と予定経路。
  3. 発火順と、次の接触で消える魔法陣。
  4. 選択カードのcost、trigger、effect、lifetime。
  5. HP、状態、deck zone。
  6. 予想damage等の集約値。

damage予測だけを出すと学習を奪うため、必ず因果列へ展開できるようにする。

時系列preview

表示モード

  • 簡易: 経路線、最終damage、消滅予定を表示。
  • 詳細: ①接触 → ②分岐 → ③耐久0/破壊 → ④後続弾直進をstep表示。
  • 差分: ドラッグ中は配置前/後で変わった経路だけを強調。
  • 不確実: randomや伏せ情報は範囲・分岐候補として表示し、確定線と混ぜない。

色と形

  • 自弾はcyan実線、敵弾はmagenta破線。色だけに頼らず線種と起点iconを併用。
  • 発火番号は円、破壊は亀裂icon、残存は盾形耐久badge。
  • 有利/不利を赤緑だけで表現せず、+ / −、矢印、patternを併用。

解決演出

連鎖の爽快感を守りながら理解可能にする。

  1. 発射前0.2秒で起点と予定線をpulse。
  2. 一つの因果まとまり（接触→分岐→hit）を視線追従可能な速度で再生。
  3. 同時に多数発火しても、主要chainのdamage数字を一つに束ねる。
  4. プレイヤー入力不可時間が長い場合、1x/2x/4xを常設。
  5. 想定外の被害時だけ、直前3〜5イベントを自動で残す。

演出skipは結果を即時適用しても、因果ログと最終盤面を失わない。

カード文面の標準

[Trigger] 魔法弾が入った時
[Effect] 左右へ1発ずつ分岐する
[Lifetime] 発火後、耐久を1失う（現在 2）
[Tag] コンボ / 分岐

状態は効果量・対象・消費契機・残寿命・stack上限を同じ順で書く。テクニカル等のビルド名を効果名の代わりに使わない。

Tutorial設計

7ステップ

Step新しく教えるもの成功条件まだ隠すもの
1一枚置いて直進弾を曲げる指定マスへ配置しhit敵弾、deck、buff
2costと複数配置cost内で2枚chain状態、破壊時効果
3耐久と消滅1枚を消し後続弾を通す敵共有
4敵も同じ盤面を使う自分は通し敵を逸らす分岐
5分岐と発火順2 targetまたは多段hit複雑なbuff
6報酬とbuild tag既存2枚と相乗する一枚を選ぶmeta

説明を読ませるのではなく、一つの安全な失敗と即時undoで学ばせる。tutorial終了時に「敵も使う」「耐久で途中から道が変わる」の二点を再確認する。

報酬・deck UX

  • 新カード単体だけでなく、現在deckのtag数と相乗候補を表示。
  • 取得後のdeck枚数と引く確率の変化を簡潔に示す。
  • Skip、削除、強化を同じ価値選択にし、常に枚数増加を強制しない。
  • 山札、捨て札、除外を異なるicon・語彙で一貫させる。
  • 報酬比較中に現在の代表chainをside panelで確認可能にする。

Map・長期UX

  • ノーマル/エリート/イベント/店/鍛冶/ボスをshape + labelで区別。
  • 未訪問部屋の報酬は確定/範囲/不明を明示。
  • 選択前に「回復機会まで2部屋」「所持金不足」等、既知情報だけを要約。
  • 敗北画面では最終build、最大chain、主な被害原因、発見したカードを表示。
  • 「もう一度」だけでなく「別の初期deck」「同じseed」の再挑戦を用意。

PC・モバイル入力

TGS/PC優先

  • hoverを補助に限定し、click/keyboardだけで全情報へ到達。
  • drag失敗時は元位置へ戻し、costを変えない。
  • Escで戻る、右clickで取り消す等を画面に常時hint。
  • pointerが無い環境でMouse.currentを直接前提にしない。

Mobile gate

  • safe area、横持ち/縦持ち、最小44〜48px相当のtouch targetを端末別検証。
  • 指で隠れるため、drag中のcard説明と配置先を上部へmirror。
  • 長押し詳細、tap選択→tap配置というdrag代替を用意。
  • hover説明、右click、細い線だけに依存しない。

Accessibility

  • font size/UI scale、色覚preset、flash軽減、screen shake、animation速度。
  • 効果音だけ/色だけで状態を伝えず、text/icon/patternを併用。
  • 連鎖の自動再生にpause、step、skipを提供。
  • keyboard/gamepad navigation順とfocus表示。
  • 日本語hard-codeを外部化し、可変長文でlayout検証。
