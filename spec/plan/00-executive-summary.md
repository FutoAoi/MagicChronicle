# 00. エグゼクティブサマリ

## 総合判断

MagicChronicleは、**自分と敵が同じ魔法陣を使う共有盤面**と、**耐久消滅によって解決途中に経路が変わる時系列パズル**に、明確な独自性がある。カードの相乗効果を数値だけでなく弾道として見せられるため、「ピースがはまった時の爆発的な爽快感」という企画意図とも整合する。

一方、現状はルールの正本、カード状態遷移、run初期化、予測UI、自動テストが不足している。実装には回復不能、消耗カード再投入、空山札参照というコアループ直結のHigh不具合が残る。**総合評価はAI Format B、リリース判断はHold**である。

## 面白さと奥深さ

- 強み: 配置一手が、自弾の大連鎖と敵弾の危険を同時に作る。
- 強み: 耐久が発火回数、盤面寿命、破壊時価値を一つに接続する。
- リスク: 分岐、複数弾、状態、破壊、敵turnの順序が見えないと、奥深さではなく予測不能になる。
- 改善原則: 本質的な複雑さを削らず、暗黙順序・用語不一致・分散状態という偶発的複雑さを下げる。

## 売れる可能性

Vitiaでは、感覚的実演を重視するLuxuriaが0.768で主軸となった。現段階で最も強い訴求は、次の15秒episodeである。

> 置く → 連鎖する → 魔法陣が砕けて道が変わる → 敵弾が同じ盤面を逆利用する

「無限に遊べる」「PC/iOS/Android対応」はまだ証拠がなく、訴求に使わない。実gameplayによる短いproofと3分試遊で、qualified demo start、wishlist、内容理解、trustを同時に検証する。

## 最優先の改善

1. 回復、消耗カード、空山札の3 Highを直し、カード保存則をテストする。
2. 発火、分岐、耐久、破壊、命中を決定的な`ResolutionQueue`へ集約する。
3. 自弾/敵弾の経路、敵意図、発火番号、耐久消滅を配置前に表示する。
4. `UIManager_Battle/Boss`のカード操作を共通化し、`GameManager`からrun/turn状態を分ける。
5. TGS版をPCの短いvertical sliceへ絞り、15秒proofと3分試遊を検証する。
6. その後にcontent、meta progression、mobileを順番に追加する。
