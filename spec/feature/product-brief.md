## 1. 製品定義

MagicChronicle（略称: マジクロ）は、5x5盤面に魔法陣カードを配置し、魔法弾の経路・分裂・強化・状態効果を設計して戦う、一人用の「魔法陣連鎖ローグライク」である。

| 項目 | 現在の定義 | 根拠 |

| ジャンル | ローグライクパズル／連鎖構築型ローグライク | `source`: SRC-PDF-001、SRC-SYS-001 |
| コンセプト | ピースが噛み合った瞬間の爆発的な爽快感 | `source`: Notionトップ、SRC-PDF-001 |
| プレイヤー価値 | 魔法の通り道を設計し、分裂と連鎖が想定以上に広がる快感と、敵にも同じ盤面を利用される緊張 | `analysis`: SRC-SYS-001 |

## 2. コア体験

1. 分岐マップから次の部屋を選ぶ。
2. 手札からコスト内で魔法陣を5x5盤面へ配置する。
3. プレイヤーの魔法弾が左側から進み、通過した魔法陣を即時発動する。
4. 方向転換、分裂、威力上昇、状態効果などが連鎖する。
5. 発動のたびに魔法陣の耐久が減り、破壊によって同一ターン内でも経路が変化する。
6. 敵の攻撃も同じ盤面と魔法陣を利用する。
7. 勝利後にカード等の報酬を選び、デッキを成長させる。

核となる面白さは、静的な最適配置ではなく「発動順と破壊によって途中から盤面の意味が変わる連鎖設計」にある。強い配置を敵にも使われるため、最大火力と防御上の安全が同じ解にならないことが本作固有の駆け引き候補である。

## 3. 世界観と進行動機

- 表設定: プレイヤーは探検者となり、古代文明の魔法陣研究施設である巨大な塔を攻略する。
- 景観: 神秘的な古代遺跡と、幾何学的に発光する魔法技術を組み合わせる。
- 通常の到達点: 塔の最奥で魔法陣の創造者クロニクルと対峙する。
- 真相: クロニクル撃破で封印が解け、兵器利用を望んだカイロスが復活する。
- 追加到達点: 裏ボスのカイロスへ挑む。

`question`: この物語が1ラン内で完結するのか、複数ランの恒久進行で開示されるのかは未定義である。

## 4. コンテンツとビルド軸

### 4.1 ラン内コンテンツ

- 部屋: ノーマル、エリート、ボス、イベント、ショップ、鍛冶。
- 報酬: カード／魔法陣を中心とする選択報酬。
- 資源候補: HP、配置コスト、手札・山札、カード耐久、所持金、各種バフスタック。

### 4.2 ビルド軸候補

- コンボ: 移動マス数に応じた威力増加、方向転換、分裂、霊陣破壊。
- バーサーカー: 自傷、疲労、筋力、カウンター、回復。
- テクニカル: 毒、バフ操作、効果再発動、高耐久の霊陣。
- 基礎: 固定ダメージ、ドロー、回復、加速、通貨獲得。

### 4.3 敵コンテンツ目標

- TGS版目標: 雑魚5、エリート2、ボス1。
- 製品版理想: 追加の雑魚10、エリート6、ボス3〜4。
- 敵行動候補: 通常攻撃、自己強化、弱い魔法陣の配置、盤面の上書き・遮断、反射、大型当たり判定。

## 6. 企画上の強み

1. 経路設計とデッキ構築を同一の魔法陣カードへ統合している。
2. 分裂による画面上の増殖が、短時間で視覚的な見せ場を作れる。
3. 魔法陣の耐久破壊により、事前計画と実行中の予想外が共存する。
4. 敵も同じ魔法陣を使うため、盤面構築が攻撃と防御の両方になる。
5. 1ターンの連鎖を映像で説明しやすく、展示・動画・ストア素材へ転用しやすい。

## 7. 主要リスク

| リスク | 影響 | 現時点の対処案 |
|---|---|---|
| 連鎖結果が読めない | 爽快感より理不尽さが勝つ | 経路プレビュー、発動順表示、危険経路の敵色表示 |
| 配置・デッキ・耐久・バフが同時に増える | 初回理解負荷が高い | チュートリアルを概念ごとの短い実戦へ分割 |
| 敵も盤面を使うルールが罰に見える | 良い配置を作る動機が下がる | 敵射線の事前提示、回避・逆利用の明確な成功演出 |
| メタ進行が未定義 | 「無限に遊べる」を支えられない | ラン内／恒久進行の契約を先に決める |
| PCとモバイル同時展開 | UI・入力・性能・safe areaの負担が増える | TGS版の主要プラットフォームと製品ロードマップを分離 |
| コンテンツ量目標が大きい | 品質と調整が分散する | 敵数よりビルド間相互作用とボス固有盤面を優先 |

## 8. 成功指標案

`hypothesis`: 企画書にKPIはないため、以下は検証用の仮置きである。

- 初見プレイヤーが説明後3分以内に、方向転換と分裂を用いた連鎖を自力で成立させる。
- 10分試遊で「敵も同じ盤面を使う」ことを理解し、それを利用または回避する判断を1回以上行う。
- 1ラン内で少なくとも2つの異なるビルド方針が成立し、報酬選択の理由を説明できる。
- TGS試遊後に、プレイヤーが本作を「魔法陣の経路を組むローグライク」と再説明できる。
